# Bitácora de uso de IA

Proyecto: ikomi-next-biktu
Herramienta utilizada: gemini
Fecha de las consultas registradas: 03/11/2026

## Entrada 1: Crear el proyecto

- Objetivo: recibir orientación para comenzar el proyecto de Next.js.
- Prompt utilizado: "primero necesito crear carpetas por favor".
- Resumen de la respuesta: la IA indicó crear la carpeta ikomi-next-biktu y después instalar el proyecto con create-next-app.
- Decisión tomada: aceptado.
- Justificación: utilicé el nombre solicitado en la evaluación con mi apellido. La instalación generó los archivos iniciales del proyecto.

## Entrada 2: Subir el proyecto a GitHub

- Objetivo: subir la versión inicial antes de continuar desarrollando.
- Prompt utilizado: "primero quiero subir en mi repositorio el proyecto y depues hacer cada commmit".
- Resumen de la respuesta: la IA explicó que necesitaba un commit inicial y proporcionó los comandos para conectar el repositorio y subirlo.
- Decisión tomada: aceptado.
- Justificación: conecté el proyecto con mi repositorio para guardar los avances durante el desarrollo.

## Entrada 3: Organizar carpetas y componentes

- Objetivo: organizar el código según las indicaciones de la evaluación.
- Prompt utilizado: "esty trabajando con componentes que sea mas ordenado".
- Resumen de la respuesta: la IA propuso separar páginas, componentes, datos, imágenes y evidencias. Al principio creó componentes que devolvían null.
- Decisión tomada: modificado.
- Justificación: la organización servía, pero los componentes vacíos todavía no cumplían el requisito de mostrar contenido. Solicité implementar los componentes.


## Entrada 4: Comprender el layout

- Objetivo: entender si layout.tsx define las rutas.
- Prompt utilizado: "layout.tsx es la lo que sevan las runtas".
- Resumen de la respuesta: la IA aclaró que las carpetas y los archivos page.tsx definen las rutas. El layout contiene el diseño compartido y children muestra la página actual.
- Decisión tomada: aceptado.
- Justificación: mantuve Navbar y Footer en el layout raíz para que aparezcan alrededor de las páginas.
